# Белка

Казахстанская карточная игра двое на двое: вы и партнёр против двух ботов. Мобильное веб-приложение: ставится на главный экран, работает без интернета, помнит партию.

## Запустить на компьютере

```bash
python -m http.server 8080
```

Откройте http://localhost:8080. Офлайн-кеш работает только на `localhost` и по HTTPS.

## Тесты

```bash
node tests/engine.test.mjs
node tests/storage.test.mjs
node tests/game.test.mjs
node tests/manifest.test.mjs
node tests/sw.test.mjs
```

`package.json` нужен только для того, чтобы Node читал файлы `js/*.js` как ES-модули. Зависимостей нет, `npm install` не нужен.

## Опубликовать на GitHub Pages

1. Создайте на GitHub пустой репозиторий, например `belka`.
2. Отправьте код:
   ```bash
   git remote add origin https://github.com/<аккаунт>/belka.git
   git push -u origin feat/pwa-v1:main
   ```
3. В репозитории: Settings → Pages → Build and deployment → Deploy from a branch → `main` и `/ (root)` → Save.
4. Через минуту приложение откроется по адресу `https://<аккаунт>.github.io/belka/`.

## Выпуск новой версии

1. Внесите изменения и прогоните тесты.
2. В `sw.js` увеличьте `VERSION`, например `1.0.0` → `1.0.1`. Если добавили новый файл, допишите его в `ASSETS`.
3. Сделайте коммит и `git push`. У игроков внизу появится «Доступна новая версия — Обновить».

## Иконки

Исходник — `icons/icon.svg`. PNG пересобираются командой `node tools/make-icons.mjs`.

## Проверить на телефоне

- **iPhone (Safari):**
  - откройте адрес;
  - «Поделиться» → «На экран "Домой"»;
  - запустите с иконки: панелей Safari нет, системная строка не перекрывает шапку, полоска «Домой» не перекрывает руку;
  - включите авиарежим, закройте и откройте снова — игра загружается.
- **Android (Chrome):**
  - откройте адрес;
  - нажмите значок «Установить» в шапке или «Установить приложение» в меню Chrome;
  - запустите с иконки и проверьте то же, что на iPhone.
- **Сохранение:** начните раздачу, смахните приложение из списка недавних, откройте снова — партия продолжается.
- **Поворот:** поверните телефон боком — появится просьба держать его вертикально.

## Устройство проекта

| Файл | Что делает |
|---|---|
| `index.html` | страница приложения и все мета-теги для iPhone и Android |
| `manifest.webmanifest` | название, иконки и режим запуска при установке |
| `sw.js` | офлайн-кеш и обновления |
| `css/app.css` | дизайн стола и карт |
| `js/engine.js` | правила, раздача и боты, без DOM |
| `js/i18n.js` | тексты на русском и казахском |
| `js/storage.js` | настройки, язык и сохранение партии в памяти телефона |
| `js/game.js` | ход партии: фазы, таймеры ботов, подсчёт глаз |
| `js/ui.js` | отрисовка и нажатия |
| `js/app.js` | запуск, офлайн-кеш, установка, обновления |
| `belka.html` | исходная версия-артефакт, оставлена для справки |
