# Белка PWA: план работ

> **Для исполнителя:** реализуйте план по задачам по навыку `subagent-driven-development` (рекомендуется, если доступны субагенты) или `executing-plans`. Шаги отмечены чекбоксами (`- [ ]`).

**Цель:** превратить файл-артефакт `belka.html` в устанавливаемое мобильное веб-приложение (PWA) для GitHub Pages: офлайн, установка на экран, сохранение партии.

**Архитектура:** обычные статичные файлы и ES-модули без сборщика. Код из `belka.html` переносится в модули почти дословно:
- `engine.js` — правила и боты, без DOM;
- `i18n.js` — тексты;
- `storage.js` — localStorage;
- `game.js` — ход партии;
- `ui.js` — отрисовка и нажатия;
- `app.js` — запуск, Service Worker, установка.

Офлайн обеспечивает `sw.js`, установку — `manifest.webmanifest`.

**Технологии:** HTML, CSS, ES2020-модули, Service Worker API, Web App Manifest, Node 18 (тесты и генератор иконок, без npm-зависимостей), Python 3 (`http.server` для локального просмотра).

**Описание:** `docs/specs/2026-10-16-belka-pwa-design.md` — исполнитель читает его вместе с планом.

## Общие ограничения

- Все адреса внутри приложения относительные (`./`, `css/app.css`, `js/app.js`): приложение живёт по адресу `<аккаунт>.github.io/<репозиторий>/`.
- Сборщика нет: файлы публикуются как есть, `npm` не используется, внешних зависимостей нет (кроме Google Fonts).
- Модули подключаются через `<script type="module">`. Нижние границы: Safari 14+, Chrome 61+.
- Только вертикальная ориентация: в манифесте `"orientation": "portrait"`, а в CSS остаётся заглушка «поверните телефон».
- Цвета: фон и тема `#0c0e12`.
- Ключи localStorage: `belka-settings`, `belka-lang`, `belka-save` (формат `{ v: 1, savedAt, S }`) и `belka-flag-<имя>`.
- Название кеша `belka-<VERSION>`, кеш шрифтов `belka-fonts`. `VERSION` объявлена в `sw.js`.
- Правила, боты, дизайн и тексты игры не меняются: модули переносят код из `belka.html` без изменения поведения.
- В GitHub пользователя ничего не отправляется (`git push`, `gh repo create`) без его отдельного согласия. Коммиты только локальные.
- Все тексты интерфейса есть на русском и казахском.

## Особое внимание при проверке

1. **Испорченное или старое сохранение** (не JSON, `v` ≠ 1, нет `S.d`) → тихо стирается, начинается новая партия, без ошибок. Тест: Task 2 (`storage.test.mjs`).
2. **Восстановление посреди переходной фазы** (`trickEnd`, `botRedeal`, `dealEnd`, ход бота) → нужный таймер запускается заново, партия доигрывается до конца без зависаний. Тест: Task 3 (`game.test.mjs`, блок 2).
3. **localStorage бросает исключения** (приватный режим Safari, переполнение) → игра работает, просто ничего не помнит. Тест: Task 2 (блок «storage that throws»).
4. **Размещение в подкаталоге**, как на GitHub Pages (`/belka/`) → страница, модули, манифест, иконки и Service Worker грузятся без 404. Проверка: Task 6, шаг с запуском из подкаталога.
5. **Обновление версии посреди партии** → после «Обновить» страница перезагружается и та же раздача продолжается. Проверка: Task 6, шаг обновления.

- [ ] **Step 4: Написать `js/storage.js`**

```js
// Безопасная работа с localStorage: любые ошибки хранилища молча пропускаются.
import { PRESETS, RULE_KEYS } from './engine.js';

export const SAVE_VERSION = 1;
const KEY_SETTINGS = 'belka-settings', KEY_LANG = 'belka-lang', KEY_SAVE = 'belka-save';

const get = k => { try { return localStorage.getItem(k); } catch { return null; } };
const put = (k, v) => { try { localStorage.setItem(k, v); return true; } catch { return false; } };
const del = k => { try { localStorage.removeItem(k); } catch { /* недоступно */ } };

export function loadSettings(){
  let saved = {};
  try { saved = JSON.parse(get(KEY_SETTINGS) || '{}') || {}; } catch { saved = {}; }
  const rules = { ...PRESETS.classic };
  if (saved.rules) for (const k of RULE_KEYS) if (typeof saved.rules[k] === typeof rules[k]) rules[k] = saved.rules[k];
  if (rules.hand !== 7) rules.hand = 8;
  const level = ['easy', 'strong', 'master'].includes(saved.level) ? saved.level : 'strong';
  return { rules, level };
}
export function saveSettings(rules, level){ put(KEY_SETTINGS, JSON.stringify({ rules, level })); }
export function loadLang(){ return get(KEY_LANG) === 'kz' ? 'kz' : 'ru'; }
export function saveLang(l){ put(KEY_LANG, l); }

export function isValidSave(o){
  const S = o && o.S;
  return !!S && o.v === SAVE_VERSION && typeof S.phase === 'string' && !!S.rules && Array.isArray(S.eyes)
    && !!S.d && Array.isArray(S.d.hands) && S.d.hands.length === 4;
}
export function loadGame(){
  const raw = get(KEY_SAVE);
  if (!raw) return null;
  let o;
  try { o = JSON.parse(raw); } catch { del(KEY_SAVE); return null; }
  if (!isValidSave(o)) { del(KEY_SAVE); return null; }
  return o.S;
}
let saveTimer = null;
export function saveGameNow(S){
  clearTimeout(saveTimer);
  if (!S) return;
  put(KEY_SAVE, JSON.stringify({ v: SAVE_VERSION, savedAt: Date.now(), S }));
}
export function saveGameSoon(S){
  clearTimeout(saveTimer);
  saveTimer = setTimeout(() => saveGameNow(S), 300);
}
export function clearGame(){ del(KEY_SAVE); }
export function getFlag(name){ return get('belka-flag-' + name) === '1'; }
export function setFlag(name){ put('belka-flag-' + name, '1'); }
```

```js
import assert from 'node:assert/strict';

// Управляемые таймеры и память вместо localStorage
const queue = new Map(); let tid = 0;
globalThis.setTimeout = f => { queue.set(++tid, f); return tid; };
globalThis.clearTimeout = i => { queue.delete(i); };
const mem = {};
globalThis.localStorage = { getItem: k => (k in mem ? mem[k] : null), setItem: (k, v) => { mem[k] = String(v); }, removeItem: k => { delete mem[k]; } };

const E = await import('../js/engine.js');
const G = await import('../js/game.js');

function step(){
  const it = queue.entries().next();
  if (it.done) return false;
  queue.delete(it.value[0]); it.value[1]();
  return true;
}
function act(S){
  if (S.phase === 'dealEnd'){ G.nextDeal(); return true; }
  if (S.phase === 'askRedeal'){ G.keepHand(); return true; }
  if (S.phase === 'play' && S.d.turn === 0){ G.humanPlay(E.id(E.legal(S.d, 0)[0])); return true; }
  return false;
}
function drive(onDealEnd){
  for (let i = 0; i < 300000; i++){
    const S = G.getState();
    if (S.phase === 'gameOver') return S;
    if (S.phase === 'dealEnd') onDealEnd?.(S);
    if (act(S)) continue;
    if (!step()) throw new Error('stuck in phase ' + S.phase);
  }
  throw new Error('too many steps');
}

// 1. Полные партии: 120 очков в каждой раздаче, первая раздача ровно 2 глаза, «яйца» (вариант «4 глаза») ровно 4
const { T } = await import('../js/i18n.js');
let notified = 0, eggsPaid = 0; G.onChange(() => notified++);
for (const preset of ['classic', 'ccw', 'short']){
  mem['belka-settings'] = JSON.stringify({ rules: E.PRESETS[preset], level: 'easy' });
  for (let g = 0; g < 60; g++){
    G.start(null);
    drive(S => {
      assert.equal(S.d.taken[0] + S.d.taken[1], 120);
      if (S.dealNo === 1 && S.result.winner !== null) assert.equal(S.result.n, 2);
      if (S.result.notes.includes(T.ru.eggsPaid)){ eggsPaid++; assert.equal(S.result.n, 4); }
    });
  }
}
assert.ok(notified > 0, 'onChange listeners are called');
assert.ok(eggsPaid > 0, '«яйца» были отыграны хотя бы раз');
assert.ok(mem['belka-save'], 'game is saved to storage');

// 2. Восстановление посреди каждой фазы доигрывается до конца
mem['belka-settings'] = JSON.stringify({ rules: E.PRESETS.classic, level: 'easy' });
const seen = new Set();
for (let g = 0; g < 60 && seen.size < 4; g++){
  G.start(null);
  for (let i = 0; i < 2000; i++){
    const S = G.getState();
    if (S.phase === 'gameOver') break;
    if (['play', 'trickEnd', 'botRedeal', 'dealEnd'].includes(S.phase) && !seen.has(S.phase)){
      seen.add(S.phase);
      const copy = JSON.parse(JSON.stringify(S));
      queue.clear();
      G.start(copy);
      assert.equal(G.getState().phase, copy.phase);
      drive();
      break;
    }
    if (act(S)) continue;
    step();
  }
}
assert.ok(seen.has('play') && seen.has('trickEnd') && seen.has('dealEnd'), 'phases covered: ' + [...seen]);

// 3. Пауза останавливает ботов, снятие паузы продолжает
G.start(null);
while (G.getState().phase !== 'play' || G.getState().d.turn === 0){ if (!act(G.getState())) step(); }
const snap = () => JSON.stringify(G.getState().d.trick) + G.getState().d.turn;
G.setPaused(true);
const before = snap();
while (step()) {}                       // остаются только подсказка и отложенное сохранение
assert.equal(snap(), before, 'nothing moves while paused');
G.setPaused(false);
for (let i = 0; i < 5 && snap() === before; i++) step();
assert.notEqual(snap(), before, 'bot moves after unpause');
console.log('game tests passed');
```

```js
// Ход партии: фазы, таймеры ботов, подсчёт глаз. Отрисовку делает ui.js через onChange.
import { SYM, RULE_KEYS, team, pts, eff, id, nextP, stepOf, makeDeal, legal, applyPlay, collect, handsEmpty, eligible, chooseCard } from './engine.js';
import { T } from './i18n.js';
import * as store from './storage.js';

let S = null, timer = null, flashTimer = null;
const view = { flash: null, sweeping: null, paused: false };
const listeners = new Set();

export const getState = () => S;
export const getView = () => view;
export function onChange(cb){ listeners.add(cb); return () => listeners.delete(cb); }
function notify(){ for (const cb of listeners) cb(); if (S) store.saveGameSoon(S); }

export const t = () => T[S.lang];
export const nm = p => t().names[p];
export const teamName = k => k === 0 ? t().us : t().them;
export function reasonText(r){ return r.kind === 'low' ? t().reasonLow(r.n) : t().reasonSuit; }

export function start(saved){
  clearTimeout(timer);
  view.flash = null; view.sweeping = null;
  if (saved){ S = saved; advance(); }
  else newGame();
}

export function newGame(){
  const lang = S ? S.lang : store.loadLang();
  const { rules, level } = store.loadSettings();
  S = { lang, rules, level, eyes:[0,0], dealNo:0, suitOf:null, eggs:false, redeals:0,
        dealer: Math.floor(Math.random()*4), phase:'idle', d:null, msg:'' };
  startDeal();
}

function startDeal(){
  S.d = makeDeal(S.rules, S.dealer, S.suitOf);
  S.result = null;
  const d = S.d;
  if (S.rules.redeal){
    for (let k = 0, p = nextP(d, S.dealer); k < 4; k++, p = nextP(d, p)){
      if (p === 0) continue;
      const r = eligible(d, p);
      if (r && (r.kind==='low' || r.suit !== d.trump)){
        S.phase = 'botRedeal'; S.msg = t().botRedeal(nm(p), reasonText(r)); advance(); return;
      }
    }
    const mine = eligible(d, 0);
    if (mine){ S.phase = 'askRedeal'; S.ask = mine; advance(); return; }
  }
  beginPlay();
}

function doRedeal(){
  S.redeals++;
  let note = '';
  if (S.redeals >= 3){
    S.redeals = 0;
    if (S.rules.redealEye){
      const k = team(S.dealer);
      S.eyes[k] += 1; note = t().threeRedeals;
      if (S.eyes[k] >= 12){ S.phase='gameOver'; S.result={winner:k, notes:[note]}; advance(); return; }
    }
  }
  startDeal();
  if (note) setFlash(note);
}

function beginPlay(){
  S.redeals = 0;
  const d = S.d;
  if (!S.suitOf){
    const h = d.holder;
    // ♣ — держателю, ♠ — партнёру, ♥ — следующему по ходу, ♦ — предыдущему
    S.suitOf = {}; S.suitOf[h]='C'; S.suitOf[(h+2)%4]='S'; S.suitOf[nextP(d,h)]='H'; S.suitOf[(h + 4 - stepOf(d.dir)) % 4]='D';
    setFlash(t().firstTrump);
  } else {
    setFlash(t().announce(nm(d.holder), SYM[d.trump]));
  }
  S.phase = 'play';
  advance();
}
export { doRedeal as redeal, beginPlay as keepHand };

function play(p, c){
  if (applyPlay(S.d, p, c)){
    S.phase = 'trickEnd';
    S.msg = t().takes(nm(S.d.lastWin), S.d.trick.reduce((a,e)=>a+pts(e.c),0));
  }
  advance();
}

function collectTrick(){
  collect(S.d); view.sweeping = null;
  if (handsEmpty(S.d)){ endDeal(); return; }
  S.phase = 'play';
  advance();
}

function endDeal(){
  const d = S.d, R = S.rules;
  const [a,b] = d.taken; const notes = [];
  const res = {a, b, ta:d.tricksCount[0], tb:d.tricksCount[1], winner:null, n:0, notes};
  if (a === 60 && b === 60){
    S.eggs = true; notes.push(t().eggs, R.eggs==='four' ? t().eggsNextFour : t().eggsNextDouble);
  } else {
    const W = a > 60 ? 0 : 1, Lo = 1 - W;
    const eggsBefore = S.eggs; S.eggs = false;
    let n;
    // «Яйца» (вариант «4 глаза») и первая раздача стоят ровно 4 и 2 глаза: без спаса и козырной надбавки
    if (eggsBefore && R.eggs === 'four'){ n = 4; notes.push(t().eggsPaid); }
    else if (S.dealNo === 0 && R.firstDeal2){ n = 2; notes.push(t().firstDealN); }
    else {
      n = W === d.trumpTeam ? 1 : 2; notes.push(W === d.trumpTeam ? t().ownTrump : t().foreignTrump);
      if (R.spas && d.taken[Lo] < 30){ n++; notes.push(t().spas); }
      if (eggsBefore && R.eggs === 'double'){ n *= 2; notes.push(t().eggsDoubled); }
    }
    res.winner = W; res.n = n;
    S.eyes[W] += n;
    if (d.tricksCount[Lo] === 0) res.golaya = R.golaya ? 'win' : 'plain';
    if (res.golaya === 'win' || S.eyes[W] >= 12){ S.dealNo++; S.result = res; S.phase = 'gameOver'; advance(); return; }
  }
  S.dealNo++; S.result = res; S.phase = 'dealEnd';
  advance();
}

export function nextDeal(){ S.dealer = (S.dealer + stepOf(S.rules.dir==='ccw' ? -1 : 1)) % 4; startDeal(); }

export function humanPlay(cid){
  if (S.phase !== 'play' || S.d.turn !== 0) return;
  const d = S.d;
  const c = d.hands[0].find(x => id(x)===cid); if (!c) return;
  if (!legal(d, 0).some(x => id(x)===cid)){
    const needSuit = d.trick.length && d.hands[0].some(x => eff(d,x)===eff(d,d.trick[0].c));
    setFlash(needSuit ? t().mustFollow : t().noAce); notify(); return;
  }
  play(0, c);
}
function botMove(){ const p = S.d.turn; play(p, chooseCard(S.d, p, S.level)); }

function setFlash(m){
  view.flash = m; clearTimeout(flashTimer);
  flashTimer = setTimeout(() => { view.flash = null; if (!view.paused) notify(); }, 2600);
}

export function setPaused(v){ view.paused = !!v; advance(); }
export function setLang(l){ S.lang = l; store.saveLang(l); advance(); }
export function applySettings(rules, level){
  const changed = RULE_KEYS.some(k => rules[k] !== S.rules[k]);
  store.saveSettings(rules, level);
  S.level = level;
  if (changed) newGame(); else advance();
}

function advance(){
  clearTimeout(timer);
  if (S.phase === 'play') S.msg = S.d.turn === 0 ? t().yourTurn : t().moving(nm(S.d.turn));
  if (!view.paused){
    if (S.phase === 'botRedeal') timer = setTimeout(doRedeal, 1500);
    else if (S.phase === 'play' && S.d.turn !== 0) timer = setTimeout(botMove, S.level === 'master' ? 450 : 700);
    else if (S.phase === 'trickEnd') timer = setTimeout(() => {
      // карты взятки уезжают к тому, кто её забрал, затем взятка засчитывается
      view.sweeping = S.d.lastWin; notify();
      timer = setTimeout(collectTrick, 380);
    }, 850);
  }
  notify();
}
```

- [ ] **Step 5: Написать генератор PNG** — `tools/make-icons.mjs`. Он рисует ту же картинку по пикселям с субпиксельным сглаживанием 3×3 и кодирует PNG через встроенный `zlib`, без зависимостей:

```js
// Рисует иконки приложения без внешних библиотек: node tools/make-icons.mjs
import { deflateSync } from 'node:zlib';
import { writeFileSync, mkdirSync } from 'node:fs';

const CRC = new Int32Array(256).map((_, n) => { let c = n; for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1; return c; });
const crc32 = buf => { let c = -1; for (const b of buf) c = CRC[(c ^ b) & 255] ^ (c >>> 8); return (c ^ -1) >>> 0; };
function chunk(type, data){
  const len = Buffer.alloc(4); len.writeUInt32BE(data.length);
  const td = Buffer.concat([Buffer.from(type, 'ascii'), data]);
  const crc = Buffer.alloc(4); crc.writeUInt32BE(crc32(td));
  return Buffer.concat([len, td, crc]);
}
export function encodePNG(w, h, rgba){
  const raw = Buffer.alloc((w * 4 + 1) * h);
  for (let y = 0; y < h; y++){ raw[y * (w * 4 + 1)] = 0; rgba.copy(raw, y * (w * 4 + 1) + 1, y * w * 4, (y + 1) * w * 4); }
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(w, 0); ihdr.writeUInt32BE(h, 4); ihdr[8] = 8; ihdr[9] = 6;
  return Buffer.concat([Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]), chunk('IHDR', ihdr), chunk('IDAT', deflateSync(raw, { level: 9 })), chunk('IEND', Buffer.alloc(0))]);
}

const C = { railHi:[59,62,96], rail:[35,37,59], feltHi:[24,169,130], feltLo:[11,110,82], stitch:[226,172,74], ivory:[251,250,245], edge:[214,208,192], gold:[217,165,33] };
const mix = (a, b, t) => a.map((v, i) => v + (b[i] - v) * Math.max(0, Math.min(1, t)));
const segDist = (px, py, ax, ay, bx, by) => {
  const dx = bx - ax, dy = by - ay, t = Math.max(0, Math.min(1, ((px - ax) * dx + (py - ay) * dy) / (dx * dx + dy * dy || 1)));
  return Math.hypot(px - ax - t * dx, py - ay - t * dy);
};
// Завиток «қошқар мүйіз»: сужающаяся спираль от верхушки стебля, левый и зеркальный правый
function hornPolyline(k){
  const pts = [], cx = 0.5 - 0.06 * k, cy = 0.5 - 0.02 * k, r0 = 0.06 * k;
  for (let i = 0; i <= 90; i++){ const t = i / 90, a = -t * 1.6 * Math.PI, r = r0 * (1 - 0.55 * t); pts.push([cx + r * Math.cos(a), cy + r * Math.sin(a)]); }
  return pts;
}
function sample(x, y, k, horn){
  // бортик
  let col = mix(C.railHi, C.rail, Math.hypot(x - 0.5, y - 0.15) / 0.9);
  // сукно: вертикальный «стадион»
  const a = 0.30 * k, b = 0.40 * k;
  const sd = segDist(x, y, 0.5, 0.5 - (b - a), 0.5, 0.5 + (b - a)) - a;
  if (sd < 0) col = mix(C.feltHi, C.feltLo, Math.hypot(x - 0.5, y - 0.45) / (0.6 * k));
  // прострочка пунктиром
  if (sd < -0.026 * k && sd > -0.034 * k && Math.floor((Math.atan2(y - 0.5, x - 0.5) + Math.PI) * 24) % 2 === 0) col = C.stitch;
  // карта со скруглёнными углами
  const hx = 0.17 * k, hy = 0.24 * k, rr = 0.035 * k;
  const qx = Math.abs(x - 0.5) - (hx - rr), qy = Math.abs(y - 0.5) - (hy - rr);
  const cd = Math.hypot(Math.max(qx, 0), Math.max(qy, 0)) + Math.min(Math.max(qx, qy), 0) - rr;
  if (cd < 0.012 * k && cd >= 0 && sd < 0) col = mix(col, [0, 0, 0], 0.25);
  if (cd < 0) col = cd > -0.004 * k ? C.edge : C.ivory;
  // золотой завиток
  if (cd < 0){
    const w = 0.011 * k;
    let dmin = segDist(x, y, 0.5, 0.5 + 0.12 * k, 0.5, 0.5 - 0.02 * k);
    const mx = x < 0.5 ? x : 1 - x;
    for (let i = 1; i < horn.length; i++) dmin = Math.min(dmin, segDist(mx, y, horn[i - 1][0], horn[i - 1][1], horn[i][0], horn[i][1]));
    if (dmin < w) col = C.gold;
  }
  return col;
}
function render(size, k){
  const horn = hornPolyline(k), buf = Buffer.alloc(size * size * 4), S = 3;
  for (let py = 0; py < size; py++) for (let px = 0; px < size; px++){
    let acc = [0, 0, 0];
    for (let sy = 0; sy < S; sy++) for (let sx = 0; sx < S; sx++){
      const c = sample((px + (sx + 0.5) / S) / size, (py + (sy + 0.5) / S) / size, k, horn);
      acc = acc.map((v, i) => v + c[i]);
    }
    const o = (py * size + px) * 4;
    buf[o] = acc[0] / (S * S); buf[o + 1] = acc[1] / (S * S); buf[o + 2] = acc[2] / (S * S); buf[o + 3] = 255;
  }
  return encodePNG(size, size, buf);
}

if (import.meta.url === `file:///${process.argv[1].replace(/\\/g, '/')}` || process.argv[1]?.endsWith('make-icons.mjs')){
  const out = new URL('../icons/', import.meta.url);
  mkdirSync(out, { recursive: true });
  writeFileSync(new URL('icon-180.png', out), render(180, 1));
  writeFileSync(new URL('icon-192.png', out), render(192, 1));
  writeFileSync(new URL('icon-512.png', out), render(512, 1));
  // maskable: всё значимое внутри центральных 80%
  writeFileSync(new URL('maskable-512.png', out), render(512, 0.86));
  console.log('icons written');
}
```

```js
// Офлайн-кеш «Белки». При каждом выпуске увеличивайте VERSION.
const VERSION = '1.0.0';
const CACHE = `belka-${VERSION}`;
const FONTS = 'belka-fonts';
const ASSETS = [
  './', './index.html', './manifest.webmanifest', './css/app.css',
  './js/app.js', './js/ui.js', './js/game.js', './js/engine.js', './js/i18n.js', './js/storage.js',
  './icons/icon-180.png', './icons/icon-192.png', './icons/icon-512.png', './icons/maskable-512.png'
];

self.addEventListener('install', e => {
  e.waitUntil(caches.open(CACHE).then(c => c.addAll(ASSETS)));
});
self.addEventListener('activate', e => {
  e.waitUntil((async () => {
    for (const k of await caches.keys()) if (k.startsWith('belka-') && k !== CACHE && k !== FONTS) await caches.delete(k);
    await self.clients.claim();
  })());
});
self.addEventListener('message', e => { if (e.data === 'SKIP_WAITING') self.skipWaiting(); });

const timeout = ms => new Promise((_, reject) => setTimeout(() => reject(new Error('timeout')), ms));

self.addEventListener('fetch', e => {
  const req = e.request;
  if (req.method !== 'GET') return;
  const url = new URL(req.url);
  if (req.mode === 'navigate'){
    e.respondWith((async () => {
      try { return await Promise.race([fetch(req), timeout(3000)]); }
      catch { return (await caches.match('./index.html')) || Response.error(); }
    })());
    return;
  }
  if (url.origin === self.location.origin){
    e.respondWith((async () => (await caches.match(req)) || fetch(req))());
    return;
  }
  if (url.hostname === 'fonts.googleapis.com' || url.hostname === 'fonts.gstatic.com'){
    e.respondWith((async () => {
      const cache = await caches.open(FONTS);
      const hit = await cache.match(req);
      const net = fetch(req).then(res => { if (res.ok || res.type === 'opaque') cache.put(req, res.clone()); return res; }).catch(() => null);
      return hit || (await net) || Response.error();
    })());
  }
});
```
